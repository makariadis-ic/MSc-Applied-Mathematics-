# Νέο Υβριδικό Σύστημα Ασαφούς Συμπερασματολογίας Τύπου Sugeno Εμπλουτισμένο με Ασαφείς Συνεπαγωγές

Συνοδευτικός κώδικας της μεταπτυχιακής διπλωματικής εργασίας

**«Νέο Υβριδικό Σύστημα Ασαφούς Συμπερασματολογίας Τύπου Sugeno Εμπλουτισμένο με Ασαφείς Συνεπαγωγές και Εφαρμογή στην Αυτόνομη Πλοήγηση Ρομπότ»**

Στέφανος Μακαριάδης, Δ.Π.Μ.Σ. «Εφαρμοσμένα Μαθηματικά», Τμήμα Πολιτικών Μηχανικών, Πολυτεχνική Σχολή, Δημοκρίτειο Πανεπιστήμιο Θράκης, Ξάνθη 2026.
Επιβλέπων: Ομότιμος Καθηγητής Βασίλειος Κ. Παπαδόπουλος.

Ο κώδικας είναι αυτός που περιγράφει το Παράρτημα Γ της εργασίας και αναπαράγει όλους τους πίνακες του Κεφαλαίου 7.

*English:* Companion code of the MSc thesis "A New Hybrid Sugeno-Type Fuzzy Inference System Enriched with Fuzzy Implications and Application to Autonomous Robot Navigation" (Democritus University of Thrace, 2026). In the proposed system each rule activation is passed through a fuzzy implication, w_r = T(μ_r, I(μ_r, c_r)), and the output is formed in the Sugeno manner. The repository contains the implication generation engine, the 56-operator implication library, the differential-drive robot simulator, the Mamdani, Sugeno and hybrid controllers, the experiment scripts, and an interactive 3D viewer.

## Περιεχόμενα

### `code/`: παραγωγή συνεπαγωγών

| Αρχείο | Περιεχόμενο |
|---|---|
| `fim_engine.py` | Μηχανή παραγωγής: αναλυτής εκφράσεων $S/T/N$, τα 8 δομικά πρότυπα, αριθμητικός αξιωματικός έλεγχος (μεταφορά της εργαλειοθήκης FoFIMT από MATLAB σε Python) |
| `implication_library.csv` | Οι 56 λειτουργικά διακριτές συνεπαγωγές με το αποτύπωμα ιδιοτήτων καθεμιάς |
| `implication_champions.csv` | Οι 13 αντιπρόσωποι των κλάσεων |

### `code/`: προσομοίωση και πειράματα

| Αρχείο | Περιεχόμενο |
|---|---|
| `robot_sim.py` | Προσομοιωτής διαφορικής κίνησης: υστέρηση επενεργητών, ολίσθηση, απόσβεση, αισθητήρας 9 ακτίνων με θόρυβο, οι 4 πίστες |
| `fis_controllers.py` | Οι ελεγκτές (Mamdani, Sugeno, υβριδικός) με κοινή βάση 11 κανόνων, και οι παραλλαγές της μελέτης αφαίρεσης |
| `run_v3_search.py` | Η αναζήτηση διαμορφώσεων στη φάση ρύθμισης |
| `run_confirm_v3.py` | Η επιβεβαίωση σε ανεξάρτητες αρχικές τιμές γεννήτριας |
| `run_final_validation.py` | Η τελική επικύρωση των 4.800 επεισοδίων (Πίνακες 7.1 έως 7.4) |
| `run_ablation.py` | Η μελέτη αφαίρεσης (Πίνακας 7.5) |

### `viewer/`: διαδραστικός τρισδιάστατος απεικονιστής

`robot_viewer_v2.html`: αυτοτελές αρχείο που ανοίγει σε οποιονδήποτε σύγχρονο φυλλομετρητή χωρίς σύνδεση στο διαδίκτυο (η Three.js και τα δεδομένα των επεισοδίων είναι ενσωματωμένα). Αναπαράγει τις τροχιές των τεσσάρων πιστών, με τις βασικές γραμμές Sugeno και Mamdani στην ίδια πίστα και με τον ίδιο θόρυβο, τις επιφάνειες των συνεπαγωγών, τα αποτελέσματα της πειραματικής εκστρατείας, υποστήριξη WebXR/VR, και ζωντανή επαναπροσομοίωση όταν μετακινούνται ή προστίθενται εμπόδια.

Τα αρχεία παραγωγής και επικύρωσης των δεδομένων του, στον φάκελο `code/`: `gen_v3.py`, `gen_baselines.py` (Python), `v3_port.js` (η μεταφορά του ελεγκτή σε JavaScript για τη ζωντανή επαναπροσομοίωση), `validate_v3.mjs`, `validate_base.mjs` (οι έλεγχοι ότι η μεταφορά αναπαράγει την υλοποίηση Python). Οι έλεγχοι συγκρίνουν με αρχεία αναφοράς (`v3_noisefree_python.json`, `base_noisefree_python.json`) που δεν περιλαμβάνονται στο αποθετήριο.

## Εκτέλεση

Απαιτούνται Python 3.10 ή νεότερη, με `numpy` και `pandas`:

```bash
pip install -r requirements.txt
cd code
python run_final_validation.py     # Πίνακες 7.1 έως 7.4, γράφει final_validation_results.csv
python run_ablation.py             # Πίνακας 7.5, γράφει ablation_results.csv
```

Τα σενάρια εκτελούνται μέσα από τον φάκελο `code/`, επειδή διαβάζουν το `implication_champions.csv` με σχετική διαδρομή. Οι διαμορφώσεις και οι αρχικές τιμές γεννήτριας είναι προκαταχωρισμένες στην κεφαλή κάθε σεναρίου. Οι έλεγχοι του απεικονιστή εκτελούνται με Node.js (`node validate_v3.mjs`).

## Σημείωση για το `fis_controllers.py`

Πέραν των ελεγκτών v1 έως v3 που περιγράφει το Παράρτημα Γ, το αρχείο περιέχει και μια μεταγενέστερη πειραματική έκδοση (`hybrid_controller_v7`) με πρόσθετο κανάλι εμπιστοσύνης. Δεν χρησιμοποιείται από κανένα αποτέλεσμα της εργασίας: όλοι οι πίνακες και τα σχήματα του Κεφαλαίου 7 προέρχονται από την έκδοση v3.
